# provenance/census-code — how data/census/ was made

This folder records how `data/census/` was made from the author's full census outputs, and the checks run on them.
The rest of the repository does not need it.

    python3 make_census_data.py          (about 10 s; runs only in the author's environment)

`make_census_data.py` reaches the private files through one variable, `AUTHOR_ENV`, the author's environment, at the
top of the script. It writes only inside this repository, in `data/census/` and `families/`. It runs four steps:

1. `census/reduce.py` on the raw outputs of the exact run. These are the 8192 files `<prog>_<pass>_<stripe>.txt/.err`,
   32 MB, in `AUTHOR_ENV/PartnersRivals1/Cannon/xq/full_out/out`. The step writes `data/census/census.csv`,
   `census_double.csv`, `passes.csv` and `m2_masks.npz`.
2. `census/compare.py` on the same raw outputs. It must end in `ALL AGREE`: 0 differing decisions in all four passes,
   and every count as in the paper.
3. The six masks of the new `m2_masks.npz` are compared with those of the first, independent computation of
   2026-09-03 (`AUTHOR_ENV/PartnersRivals/Figures/m2_masks.npz`). That computation ran
   `PartnersRivals/check/pairs.c`, byte-identical to `census/pairs.c`, on 12 local cores, with defensibility by a
   separate Floyd–Warshall script. All six masks are **bit-identical**.
4. `families/families.py` is run on the new data, and its `families.txt` is compared with the original
   (`AUTHOR_ENV/PartnersRivals/check/families.txt`). They are **identical**.

## The runs behind the data

| what | where and when |
|---|---|
| exact census, both programs, all four passes | Cannon job **48068392**, `test` partition, 48 cores, 2026-09-23. It COMPLETED 0:0 in 164 s of wall time, as recorded by `sacct` in the kit's `RESULT.md`. `reduce.py` checks that every `.err` holds only the expected one-line receipt, with no error or overflow message. An earlier submission, 48068170, was cancelled while pending on Resources and resubmitted with fewer cores |
| its probe (4 stripes, 32 passes) | Cannon job **48068015**, 16 cores, 22 s, COMPLETED |
| first computation (double precision, masks, families) | `PartnersRivals/check/pairs.c` on the 12 local cores, 2026-09-03, at most 70 s per pass |

The raw outputs of the exact run are not deposited; the repository holds reduced data only. They are
regenerated by `census/cannon/` or `census/cannon/task.sh`, and a local 4-stripe probe reproduced 32 of them byte for
byte (see `census/README.md`). A compressed copy of all 8192 files is 3 MB (`out_full.tgz` in the author's kit
folder), so they could be added later if wanted.

## Verification (2026-09-24)

`python3 make_census_data.py` was run once, and every step above ended in agreement. Running `census/reduce.py` twice
on the raw outputs gives byte-identical tables, and `m2_masks.npz` is byte-identical as well.
