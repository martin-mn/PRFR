# families — the family descriptions of the friendly rivals (SI §7, Methods "Family descriptions")

This folder describes each set of friendly rivals as a union of wildcard patterns. It covers the four open wedges W,
N, E and S, the defensible reading of S, and the two overlaps W∩S and E∩N.

- A **pattern** is 16 symbols over {0, 1, *}. Position j is state j = 4·(most recent outcome) + (the outcome before),
  with CC=0, CD=1, DC=2, DD=3 written own action first; 1 = C, 0 = D, * = either.
- A pattern is **prime** for a set if every strategy it names is in the set and no further position can be made a
  wildcard. The primes are generated by Quine–McCluskey merging.
- A **family description** is a minimum cover of the set by primes. It is found as an exact set cover by integer
  linear programming (`scipy.optimize.milp`). Uniqueness is decided by forbidding each chosen prime in turn and asking
  whether a cover of the same size remains.

    python3 families.py          (about 2 s; numpy and scipy >= 1.9)

| file | what |
|---|---|
| `families.py` | the script. It reads the six masks from `../data/census/census.csv` (via `../census/censuslib.py`) and writes the two files below. Importing it defines the functions and the sets without running the analysis, which is how `../SITable4/` uses it |
| `families.txt` | the full description of each set. It gives the common fixed positions, the number of primes and their wildcard counts, the minimum cover and whether it is unique, and each family with its 4×4 table (rows: most recent outcome; columns: the outcome before) and its first member codes |
| `covers.csv` | the covers in machine-readable form: set, set size, uniqueness, family number, pattern, wildcards and members: 79 rows, one per family (after 11 comment lines and the header) |

## What it gives

| set | strategies | primes | minimum cover | unique |
|---|---:|---:|---:|---|
| W (mutual cooperators, rivals for T>S) | 8 | 1 | 1: `111*000101*1*010` | yes |
| N (alternators, rivals for T>S) | 80 | 4 | 4 | yes |
| E (alternators, rivals for T<S; the mirror of N) | 80 | 4 | 4 | yes |
| S (mutual cooperators, rivals for T<S) | 1519 | 56 | 42 | no |
| S, defensible reading | 1036 | 33 | 24 | no |
| W ∩ S | 2 | 1 | 1: `111100010111*010` | yes |
| E ∩ N | 8 | 3 | 3 | yes |

The paper says that for S "one of the minimal covers is included in the computed output". That cover is the 42
patterns of S in `covers.csv` and `families.txt`. Which minimum cover the solver returns is not determined by the
problem. The one deposited here is what scipy 1.10.0 (HiGHS) returns, and it is identical to the cover of the
original computation.

## Inputs and outputs

- Input: `../data/census/census.csv`, the columns `eff_cc`, `eff_alt`, `riv_p`, `riv_m`, `def_p`, `def_m`.
- Output: `families.txt` and `covers.csv`, next to the script.
